앞으로 공부하고 활동한 내용을 꾸준히 기록하기 위해 GitHub Pages로 개인 블로그를 만들었다.
이 글은 GitHub Pages가 무엇인지, 그리고 이 블로그를 어떤 과정으로 만들었는지 정리한 기록이다.

## GitHub Pages란

GitHub Pages는 **GitHub 저장소에 올린 파일을 그대로 웹사이트로 공개해 주는 무료 호스팅 서비스**다.
서버를 따로 빌리거나 관리할 필요 없이, 저장소에 파일을 올리기만 하면 사이트가 갱신된다.

- 저장소 이름을 `아이디.github.io`로 만들면 `https://아이디.github.io` 주소로 접속할 수 있다.
- HTML 파일을 직접 올려도 되지만, 보통은 **정적 사이트 생성기**를 함께 쓴다.

### 정적 사이트 생성기와 Jekyll

글을 쓸 때마다 HTML을 직접 만드는 건 번거롭다. 정적 사이트 생성기는 **Markdown으로 쓴 글을 HTML 페이지로 바꿔 주는 도구**다.
Jekyll은 GitHub Pages와 궁합이 좋은 대표적인 정적 사이트 생성기다.

- `_posts` 폴더에 `YYYY-MM-DD-제목.md` 형식으로 글을 넣으면 게시글이 된다.
- 글 맨 위의 front matter(`---`로 감싼 부분)에 제목, 날짜, 카테고리, 태그를 적는다.
- 사이트 전체 설정은 `_config.yml` 파일 하나에서 관리한다.

## 만든 과정

### 1. 테마 고르기

기술 블로그에 맞게 글 읽기가 편하고, 카테고리·태그·목차·다크 모드를 지원하는 **Chirpy** 테마를 골랐다.

### 2. 템플릿으로 저장소 만들기

Chirpy에서 제공하는 `chirpy-starter` 템플릿으로 `enloa-0.github.io` 저장소를 만들었다.
템플릿을 쓰면 테마 설정과 배포 설정 파일이 처음부터 들어 있어서 시작이 빠르다.

### 3. 배포 방식 설정

저장소의 **Settings → Pages → Build and deployment**에서 Source를 **GitHub Actions**로 바꿨다.
이렇게 하면 main 브랜치에 커밋이 올라올 때마다 Actions가 자동으로 사이트를 빌드하고 배포한다.
배포 상태는 저장소의 **Actions** 탭에서 확인할 수 있다.

### 4. 기본 설정 바꾸기 (`_config.yml`)

| 항목 | 값 | 의미 |
|---|---|---|
| `lang` | `ko-KR` | 날짜·UI 문구를 한국어로 표시 |
| `timezone` | `Asia/Seoul` | 글 작성 시각을 한국 시간 기준으로 표시 |
| `title`, `tagline` | 블로그 이름, 한 줄 소개 | 사이드바 상단에 표시 |
| `url` | `https://enloa-0.github.io` | 사이트 주소 (끝에 `/` 없이) |
| `theme_mode` | `dark` | 기본 테마를 다크 모드로 고정 |

### 5. 카테고리 구성

활동을 성격별로 나눠 기록하려고 6개 카테고리를 정했다.

- 개발
- CTF/Wargame
- Bug Bounty
- 블로그/기술문서
- 논문/컨퍼런스
- 공모전/자격증

Chirpy는 글의 front matter에 `categories: [개발]`처럼 적으면 카테고리 페이지에 자동으로 분류된다.
각 카테고리가 무엇을 다루는지는 About 페이지에 정리해 두었다.

## 앞으로

- 활동할 때마다 해당 카테고리에 기록을 남긴다.
- 처음 보는 사람도 이해할 수 있게, 자료를 옮기기보다 내가 이해한 방식으로 풀어 쓴다.
- 사이트가 익숙해지면 프로필 사진, 댓글 기능도 추가해 볼 생각이다.
